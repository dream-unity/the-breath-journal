Dream Unity · Downloads

Keep a video.
Take its audio with you.

Set up the free Download Helper on a Windows, macOS or Linux computer. Then use Download video or Download MP3 beneath any linked video in your mind map.

This feature needs the helper running on the same computer as your browser. A phone or tablet cannot use a helper running on another device.

1. Install the required tools

Install Python 3.10 or newer, FFmpeg (including ffprobe), and Deno using their instructions for your computer.

FFmpeg and Deno must be available from your terminal. Open a new terminal after installing them. The helper will report any missing tools when you connect.

Download the helper

Open a terminal in the folder where you saved dream-unity-helper.py. Expand the instructions for your computer:

Windows

Run these commands in PowerShell. The first two commands create a separate environment and install the downloader:

py -m venv dream-unity-downloads-env
dream-unity-downloads-env\Scripts\python -m pip install --upgrade "yt-dlp[default]"
dream-unity-downloads-env\Scripts\python dream-unity-helper.py
macOS or Linux

Run these commands in Terminal. The first two commands create a separate environment and install the downloader:

python3 -m venv dream-unity-downloads-env
dream-unity-downloads-env/bin/python -m pip install --upgrade "yt-dlp[default]"
dream-unity-downloads-env/bin/python dream-unity-helper.py

On Linux, your distribution may require its python3-venv package first.

2. Connect your browser

  1. Keep the helper's terminal window open. Copy the connection code it displays.
  2. Return to your existing mind-map tab. Beneath a YouTube player, open Download setup, paste the code, and choose Connect helper.
  3. If your browser asks, allow this site to connect to the helper on your local computer.
  4. Choose Download video or Download MP3. When complete, the filename appears beneath that video. Use Open downloads folder to find it.

Files are saved in Downloads → Dream Unity in your home folder. Video downloads contain the complete video, up to 1080p; a timestamp in the YouTube link does not trim the download. MP3 downloads contain the complete audio.

The connection code is kept only in this page's memory. Reconnect after reloading the page, and use the new code whenever you restart the helper.

Next time

Run only the final command for your computer to start the helper again, then reconnect using its new code. Press Ctrl + C in the terminal when you have finished. Completed downloads remain on your computer.

The helper handles one download at a time. You can keep watching, editing your map, or switching ideas while it works. Each progress message stays associated with the video and idea that started it.

If a download cannot complete

  • Cannot connect: check the helper is running on this computer, paste its current code, and check the browser's local-network permission for this site. No remote server is needed.
  • Missing tools: install the tools listed by the helper and restart it. For yt-dlp updates, repeat the installation command above.
  • Video unavailable: YouTube may restrict downloads or require sign-in, and its delivery system can change. This helper does not import browser cookies, sign into YouTube, or bypass protected content. A playable embed does not guarantee a downloadable file.
  • Download interrupted: keep the computer awake and the helper running. The helper limits each job to one hour, videos to three hours, and working files to 2 GiB. Cancel an active download beneath its player if needed.

Download only content you own or have permission to save. This helper uses yt-dlp and FFmpeg. Requests for the chosen video go directly from your computer to YouTube; mind-map titles, notes and recordings are not sent to the helper. Your own Internet connection and disk space are used.
